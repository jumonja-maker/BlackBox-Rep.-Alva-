# BLACK.BOX Universal

**Самостоятельная программа наблюдения за процессами Windows — версия 0.3.2**

BLACK.BOX позволяет выбрать запущенный процесс, наблюдать за системными показателями и сохранять отчёты локально. Программа не изменяет стороннее приложение, не внедряется в его код и не объявляет причины внутренних ошибок доказанными без достаточных данных.

## Скачивание и запуск

Загрузите `BLACK.BOX-Universal-Windows.zip` из [GitHub Releases](https://github.com/jumonja-maker/BlackBox-Rep.-Alva-/releases/latest), распакуйте **всю папку** и запустите двойным щелчком `BLACK.BOX-Universal.exe`. Необходимые библиотеки уже находятся в ZIP. Не удаляйте `_internal` и служебный `BLACK.BOX-Maintenance.exe`.

В приложении пять вкладок: **Обзор**, **Процессы**, **Журнал событий**, **Отчёты**, **Настройки**. Выберите доступный процесс во вкладке «Процессы», нажмите «Начать наблюдение» и затем «Остановить». Программа сохранит `session.sqlite3`, `report.json` и `report.html`. В «Отчётах» можно открыть HTML или сравнить ранее сохранённые сеансы.

Измеряются CPU, RSS выбранного процесса и другие доступные системные счётчики. Недоступное значение показывается как отсутствие данных, а не вымышленный ноль. Отчёты остаются на вашем компьютере; приложение не устанавливает службы и не требует учётной записи.

## Обновление

Кнопка «Обновить» проверяет официальные выпуски [GitHub Releases](https://github.com/jumonja-maker/BlackBox-Rep.-Alva-/releases), а не изменения исходников в `main`. Проверяются версия, размер ZIP и его SHA-256. При подтверждении установки отдельный служебный EXE заменяет файлы после закрытия программы. Данные сеансов в «Документах» должны сохраняться.

## Разработка

Python 3.11+, команды `pip install -r requirements.txt`, `pip install -e .`, `python app.py`, `python -m unittest discover -s tests -v`. Основное ядро называется `blackbox_core`.

Это инструмент наблюдения, а не автоматический ремонт Windows или средство достоверного установления причин ошибок сторонних программ.
