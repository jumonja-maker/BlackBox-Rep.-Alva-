# BLACK.BOX Universal — main, version 0.3.4

The standalone Windows observer now includes visible confirmation of attachment to a specific process PID, shown in the Current Session panel and updated on Attach, Start and Stop in RU/EN. The feature is not displayed without an explicitly selected process. Process picking via EXE path (v0.3.3), local reports, five sections and SHA-256-verified portable updater remain unchanged.

Automated Windows/Linux QA and frozen-executable smoke checks are required before GitHub Actions publishes the official v0.3.4 Release. Physical Windows UI testing and binary/update acceptance remain separate checks. No proprietary platform runtime is included.
