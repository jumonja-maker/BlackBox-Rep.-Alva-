Новый анализатор читает весь выбранный диапазон v1/v2, отдельно сохраняет наблюдения, производные признаки, пользовательские заявления, альтернативы, ограничения и coverage. Контрактные 513 инцидентов доступны целиком; это синтетическая проверка, не доказательство 513 настоящих зависаний Windows.

Карточки дают реальные ближайшие снимки до/в конце/после инцидента, ресурсы, потоки, доступные Windows/WCT/trace события, права/ограничения и неполный post-context. Корреляция не объявляет причину.

На существующей странице событий — единый поток с фильтрами источника/уровня/экземпляра/времени/текста, keyset страницами и переходом к реальному интервалу без смены цели. Старые источники без времени остаются в прежнем представлении, а не получают вымышленный timestamp.

Шкала дополнена дорожками действий, пользователя, инцидентов, Windows, WCT, трасс и состояния наблюдателя. Дорожки агрегируют весь диапазон, не только первую страницу. SQL и анализ выполняются в прежних фоновых/изолированных владельцах, не при отрисовке.

## Сохранение этапа: данные, восстановление и хранение

- Раздельное окончательное удаление выбранных завершённых собственных записей из корзины: отдельный просмотр/подтверждение, одноразовый token, нативная идентичность, журнал вне удаляемой папки, продолжение после сбоя. Новые/заменённые файлы блокируют устаревшее удаление. Никакого рекурсивного shell удаления и автоматической очистки.
- Мягкие лимиты времени/логического объёма и кэшированные общие пороги. Неизвестные размеры не считаются нулём; физическая квота и физически освобождённые байты не заявляются. При превышении сбор останавливается с сохранением файлов.
- Экспорт получает собственный stage, журнал и SHA-256. После аварийного выхода процесса можно явно завершить подготовленную публикацию либо подтвердить очистку проверенных временных файлов. Незавершённая сборка не становится пустым успешным экспортом; новые/заменённые файлы сохраняются для просмотра.
- Все 513 контрактных находок попадают в JSON/CSV/HTML; сортировка вынесена в SQLite, spool не публикуется. HTML экранирует данные, CSV защищён от формул, включая ведущие пробелы. Данные по умолчанию дополнительно исключают известные notes/comments; универсальный поиск секретов не заявляется.
- Ресурсная история процессов, корень и дерево отдельно; сумма RSS по связанным реальным снимкам не равна сумме индивидуальных пиков и может повторять общие страницы.
- Полные поля capability/прав/opt-in/ОС/точности/ограничений и bounded окно задержек датчиков. Ошибка health отдельного источника не обрушает другие источники.
- Исправлены закрытие research SQLite при сбое Start и завершение открытого USER-этапа после закрытия первичного сборщика. Несэмплированный tail CaseBook учитывается явно при запросе полного сеанса.
