## Работающий пользовательский путь

- На существующей странице «Отчёты» есть сворачиваемая библиотека. Шестой
  страницы нет. Сохранены RU/EN и обычная автономная установка приложения.
- Новая запись индексируется при Start и Stop изолированным владельцем.
  В цикле измерений нет обращений к каталогу. Ошибка индекса отражается в
  `library_health`, но не останавливает базовую запись и не меняет её статус.
- Поиск по программе, сценарию, его версии, версии программы, нагрузке и
  профилю работает по отдельной SQLite. Страница — максимум 50 записей (API
  максимум 100), курсор `(started_ns, entry_id)`, без OFFSET/обхода всех папок
  при отрисовке. Старый ответ не заменяет новый запрос. Панель отправляет
  только один запрос страницы одновременно, не опрашивает индекс по таймеру
  измерений. Поиск текста отложен на 300 мс после ввода.
- Показаны сохранённые метаданные: время с локальным смещением UTC, состояние,
  версии, повторы, отсчёты, профиль/интервал, оценка размера и её статус.
  Активная запись имеет начальные, а не выдуманные живые итоги. Неизвестный
  размер не превращается в ноль.
- Прежние записи добавляются явным ограниченным поиском или выбором папки.
  Порция до 50 записей, API максимум 100; 5 секунд с проверкой между записями.
  Одно чтение SQLite имеет progress handler, вся операция — жёсткий дедлайн
  отдельного процесса. Каталог не требует интернета.
- Открытие использует существующий потоковый читатель интервалов v1/v2,
  не вызывает attach и не меняет PID наблюдения.
- Сравнение выбирает две индексированные записи и порядок «до → после».
  Сохраняется сравнение ресурсов; разные версии сценария добавляют
  несовпадение условий. Отсутствующая версия старой записи указана отдельным
  предупреждением. Причинность/ускорение не объявляются доказанными.

## Хранение и границы безопасности

По умолчанию дни=0, объём=0, `automatic_deletion=false`. Пороги составляют
только список кандидатов. Внешние папки не входят в объём принадлежащих
приложению записей. Размеры сохранены при остановке/явном обновлении и являются
оценкой метаданных, а не живой жёсткой квотой.

**Корзина обратима и не освобождает место на диске. Окончательного удаления
и автоматического соблюдения квоты нет.** Интерфейс и машинные ответы явно
сообщают `bytes_freed=0`. Поэтому M-035 остаётся PARTIAL.

Перенос требует списка с папками/размерами и отдельного подтверждения, ответ
по умолчанию — «Нет». Подтверждение одноразовое, действует 5 минут; очередь
не более 128 неиспользованных планов. Повторно проверяются корень, маркеры,
идентичность каталога, метаданные дерева, конечное состояние и журналы трасс.
Изменившаяся запись требует нового просмотра. Рекурсивного удаления нет.

Допускаются новые записи `session-<UUID>` непосредственно в выбранном корне,
помеченные приложением, с подтверждённым завершением ресурсов. Прежняя/внешняя
запись не становится принадлежащей приложению после поиска. Активные и
неподтверждённые записи, незавершённые ETW-журналы, симлинки/reparse points
и конфликты назначения блокируют перенос.

Перенос в том же томе атомарен без замещения назначения: Windows MoveFileW,
Linux renameat2(RENAME_NOREPLACE). Журнал и MOVING_TO_TRASH/RESTORING записываются
до действия. Явная сверка после сбоя смотрит обе локации и восстанавливает
индекс. Если обе/ни одна папка найдены, результат —
MANUAL_RECOVERY_REQUIRED_NO_FILES_CHANGED, без удаления. Захват состояния
в SQLite защищает от одновременной заявки второго экземпляра. Восстановление
не заменяет существующую папку. Пустые журналы/контейнеры не удаляются сами.

Локальный маркер **не цифровая подпись**. Fingerprint сравнивает идентичность
и статистику файлов, не хэширует весь корпус; он не обещает защиту от
враждебной синхронной модификации с подделкой метаданных. Прочитанные исходники
сохраняют класс UNVERIFIED_IMPORT, не становятся аттестованными сведениями ОС.

## Изоляция и нагрузка

Индекс имеет отдельные application_id/schema/root_id. Посторонняя база с тем
же именем отвергается без изменения содержимого. Схема и идентичность индекса
создаются одной транзакцией; исходные таблицы наблюдений не мигрируют.

Все действия панели используют allowlist `operation_worker.py`; корень
назначает владелец записи, аргумент операции его не подменяет. Поиск, импорт,
сравнение, политика и перемещение выполняются в управляемом процессе,
не в Qt/основном sampler. Сохраняются очередь 8, одна операция, результат
до 4 MiB и Windows Job Object. Start/Stop/закрытие отменяют эти операции;
неподтверждённое перемещение сверяется по журналу. Целевой процесс не убивается.

Индексирование — дважды за сеанс. Оценка размера при Stop ограничена
10 000 элементов, глубиной 12 и 0,5 секунды; превышение даёт неизвестный размер.
Проверка перед переносом имеет бюджет 2 секунды на запись и отказывается
при неполном обходе. Эти бюджеты не обещают аппаратную latency файловой
системы: принудительные дедлайны применяются к отдельным процессам операций.

## Проверки этой части

Новые регрессии проверяют индекс/кириллицу/курсор/буквальные `%` и `_`,
отсутствие scandir при запросе списка, внешние/активные записи, незавершённый
native-владелец/ETW, изменение записи после просмотра, истечение/повтор
согласия, очередь планов, конфликт назначения, другой экземпляр, сверку
журнала, ошибку индекса без остановки записи и отсутствие индекса в tick.

Qt-тесты используют настоящий изолированный владелец: поиск и устаревшие
ответы, открытие без смены PID, сравнение, отмену/подтверждение корзины,
восстановление и неизменный SHA-256 базы. Русская панель проверяется при
минимальной ширине окна. Сборка требует библиотечные модули в PyInstaller PYZ.

`app.py --research-e2e <новый-каталог>` включает прежний цикл
GUI→helper→клиент→действие→ZIP→verify→compare, затем две записи в индексе,
открытие, сравнение по ID, план без переноса, явное QA-согласие, возврат через
UI, прежний SHA-256, RU/EN PNG и выход helper с кодом 0. Настоящий диалог
«Нет»/«Да» отдельно проходит Qt-регрессию, не подменяется QA-согласием.

Локально: **377 тестов, 365 PASS, 12 SKIP**. Реальный E2E: PASS, разные
GUI/helper PID, библиотека/возврат файлов/SHA-256/exit 0 подтверждены; русская
PNG просмотрена. Внешняя адаптация self-PID из-за особенностей executor
не входит в продукт/hosted CI. Новые Windows/frozen результаты нужно
подтвердить на точном SHA; старые зелёные прогоны их не заменяют.
