# Diagnostics and evidence contract (BlackBox schema v1)

This is **not Alva's v1 protocol**. The bridge converts a tiny, explicitly validated summary into the genuine Alva protocol when installed.

## Locally observed facts

- Session metadata: `schema_version=1`, opaque session UUID, numeric PID, creation/closing UTC, exit code. PID alone is not identity; runtime adapter additionally checks creation time.
- Samples: `seq`, monotonic elapsed milliseconds, optional RSS bytes / CPU percentage / thread count / I/O bytes / descendant process count. `null` = unavailable, **not zero**. No sampling of user documents, environment variables, command lines or user names.
- Failures: enumerated `PROCESS_EXITED`, `PID_REUSED`, `ACCESS_DENIED`, `SAMPLE_UNAVAILABLE`, `DEPENDENCY_MISSING`, `STORAGE_ERROR`, `INVALID_DATA`; distinct stage (`discovery`, `attach`, `sample`, `storage`, `report`, `platform`). No stacktrace copied from the target application.
- Report: `root_cause=UNKNOWN`, `root_cause_confidence=UNKNOWN`, `execution_attested=false`. `closed` means observer session closed, **not** observed application exited cleanly.
- User-facing results: HTML and JSON describe observer evidence, unavailable fields and uncertainty. CPU/RAM peaks do not establish root cause. No AI handoff is generated by default.

## Provenance and AI safety

Host-generated data and real target telemetry must be distinguished. The report is an observation of a local sampling process, not a signed, audited, or independently trusted attestation. External data is never promoted into system/developer instructions for an AI agent. Any subsequent code modifications require independent review, verification, and user authorization.

## Schema evolution

Reject unknown database schema versions; do not infer new fields. An adapter for richer in-application telemetry must declare its own schema, producer identity, PII policy, bounded framing, sequence gap semantics, clock model, and deliberate enablement in the observed application. No implicit instrumenting or injection.
