# BLACK.BOX: патч рабочего процесса специалиста

Статус: исходники/разработка v0.6.0. Последний опубликованный комплект, проверенный для этого патча, — v0.5.4. Этот документ объясняет рабочий процесс и границы изменений; фактические результаты CI, SHA, PR и оставшиеся дефекты должны быть указаны в отдельном итоговом отчёте. Документ не подтверждает публикацию, физическую приёмку или успешное выполнение всех проверок.

## Повторяемая работа с записью

**Выбрать процесс → проверить цель/профиль → записать нагрузку → остановить → явно открыть результат → выбрать интервал → изучить факты → сравнить/экспортировать.**

1. Найдите работающий экземпляр на «Процессах», подключитесь и проверьте PID/время создания в «Обзоре». Файл, строка истории и подтверждённая живая цель — разные состояния.
2. Выберите Standard/Detailed/Incident Burst и интервал. Нажмите начало наблюдения и воспроизведите нагрузку. Дополнительные ETW, EventPipe и дампы запускаются отдельно.
3. Остановите наблюдение и проверьте завершение/путь сохранения. Генерация отчёта имеет отдельное состояние от записи измерений.
4. Нажмите **«РЕЗУЛЬТАТ»** в «Обзоре» или **Ctrl+Shift+R**, когда результат готов. Полное имя действия в подсказке — «Открыть результат записи». Переход явный: Stop сохраняет текущую страницу. Открывается последняя живая запись как сохранённый анализ только для чтения.
5. В «Отчётах» проверьте папку и диапазон открытого анализа. Переходы к разделам позволяют быстро открыть шкалу, находки, библиотеку, действия захвата и технические данные. Они перемещают по существующим инструментам внутри страницы.
6. Для другой записи используйте открытие сохранённого сеанса/библиотеку. Это меняет контекст анализа и не подменяет текущий живой PID. До сравнения проверьте совместимость условий.
7. Копирование контекста использует локальный буфер обмена. Путь и пользовательские данные могут быть чувствительными; проверьте их перед передачей.

## Навигация и читаемость свидетельств

| Команда | Действие |
| --- | --- |
| Ctrl+1…6 | «Обзор», «Процессы», «События», «Отчёты», «Настройки», Trace Decoder |
| Ctrl+L | Открыть «Процессы» и сфокусировать поиск |
| «РЕЗУЛЬТАТ» / Ctrl+Shift+R | Перейти к сохранённым данным последней готовой записи |
| Переходы разделов «Отчётов» | Открыть нужную часть текущей страницы с сохранением её инструментов |
| Копирование контекста анализа | Скопировать видимый контекст в локальный буфер |

Ctrl+6 применим при наличии Decoder. Старый пятистраничный embedding API сохраняется. Навигация не запускает запись, вмешательство или UAC. Готовность результата и фактический статус определяют доступность соответствующей операции.

Находки используют читаемые RU/EN-формулировки и представление измеренных фактов. Полные технические данные сохраняются. Перевод и форматирование не превращают неизвестное значение в ноль, пользовательскую пометку — в факт ОС, а совпадение по времени — в доказанную причину.

## Область изменений

Сохранены шесть главных страниц и существующие экспертные инструменты. Deep Inspection и конструктор цепочек остаются внутренними рабочими областями. Выбор записи, диапазона, живой цели, импортированной трассы и диагностического запуска остаётся явным.

OBSERVE читает доступные счётчики и не меняет память цели. Отдельные INSPECT/INTERVENE могут читать чувствительные данные, кратко приостанавливать процесс, выполнять отладочные действия и изменять выбранные байты; действуют подтверждение конкретной операции/цели, проверка идентичности и применимый доступ. Админ-сеанс не отменяет этих условий. Неизвестные выполнение и очистка остаются неизвестными.

Патч улучшает доступ к существующим сведениям и операциям. Он не добавляет новый диагностический источник и не устанавливает внутреннюю причину по CPU/RSS/I/O. Зелёный hosted CI не заменяет физическую Windows 10/11, интерактивный Secure Desktop, ассистивные средства или любую длительность работы. Неподписанный EXE сохраняет ограничения SmartScreen/антивируса; контрольная сумма подтверждает байты, а не безопасность и доверенное происхождение.
