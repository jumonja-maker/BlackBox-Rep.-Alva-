# Human-first product contract

Download full portable ZIP, extract it, double-click the main EXE, choose a process, attach, observe, stop and read a local report. Use five tabs only: Overview, Processes, Event Log, Reports, Settings. Keep the interface bilingual RU/EN. No user-facing development-lab views, Python setup, account requirement or remote server.

Make errors specific and conservative. A resource spike is not proof of a program defect. Protected system processes may be unavailable. Preserve existing evidence during updates/removal.
