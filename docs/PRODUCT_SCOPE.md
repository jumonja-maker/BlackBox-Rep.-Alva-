# Scope of BLACK.BOX Universal

An offline, independent Windows app to observe a user-selected process. Capture accessible process counters and event timeline, keep reports locally, compare sessions and provide conservative human-readable explanations of the measurements' limitations. Do not market it as an automatic repair tool, full Windows diagnostic suite, arbitrary application internal debugger, or proof of root cause.

Users may select a file before it is running. EXE selection can resolve an existing process with an exact file-path match or explicitly start it after approval. Other file formats are read-only metadata targets, not executable observation sessions. This is neither a malware scanner nor a generic installer/script runner.
