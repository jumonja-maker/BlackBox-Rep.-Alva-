# Five-page interface contract

Overview, Processes, Event Log, Reports and Settings are the only top-level pages. Keep compact one-line page breadcrumbs; do not reintroduce decorative marketing headlines. Maintain desktop controls, bilingual labels, accessible process selection, CPU and selected-process RSS readouts, chart gaps for unavailable values, durable reports and clearly labeled update/maintenance actions. Keep the primary executable's taskbar icon consistent with its Explorer icon.
